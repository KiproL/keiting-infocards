# Иконки карточек и частей

Иконки нарисованы в стиле `res/drawable/icon_cards_*.xml`. Окно 512×512, только линии. Каждая линия в четырёх слоях: широкое свечение, мягкое свечение, основная линия и светлая сердцевина. Градиент тот же: `#D21CFF → #5B1BFF → #0A63FF`.

| Папка | Что | Сколько |
|---|---|---|
| `cards/` | новые карточки из `cards/index.json`, у которых нет своей плитки | 11 |
| `parts/` | вторые и следующие части карточек из `tree/curriculum.json` | 67 |

У каждой иконки два файла с одинаковым рисунком:
- `<id>.xml` — векторный ресурс Android. Его можно положить в `res/drawable` как есть.
- `<id>.svg` — тот же рисунок для загрузки по сети.

Соответствие «карточка или часть → файл» лежит в `index.json`. Ключ — route карточки (`cards_colours`) или ID части (`b2_wish_past`). Посмотреть все иконки разом можно в `preview.png`.

## Как иконки попадают в приложение

Показ сделан в приложении, коммит `cbb9a8c`: файлы `.svg` загружаются по сети.

- **Плитка карточки.** `CardIcons.cardIcon(route)` ищет карточку в `index.json`. Нашлась — на плитке «Теории» своя иконка, нет — иконка папки, как раньше.
- **Часть.** На экране курса рядом с названием части стоит иконка из `parts`. Для первой части берётся иконка карточки, если она есть.
- Загружает Coil с декодером `io.coil-kt:coil-svg`. Пока иконка грузится или если сети нет, видна встроенная иконка.

Новая иконка появляется без обновления приложения: достаточно положить файлы и добавить строку в `index.json` (это делает `build.py`).

## Как добавить или поправить иконку

Рисунки описаны в `designs_cards.py` и `designs_parts.py`, общие функции — в `neon.py`: шрифт из одной линии, рамки, круги, стрелки. Собрать файлы заново:

```
python3 icons/build.py
```
