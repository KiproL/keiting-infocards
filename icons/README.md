# Иконки карточек и частей

Иконки нарисованы в стиле `res/drawable/icon_cards_*.xml`. Окно 512×512, только линии. Каждая линия в четырёх слоях: широкое свечение, мягкое свечение, основная линия и светлая сердцевина. Градиент тот же: `#D21CFF → #5B1BFF → #0A63FF`.

| Папка | Что | Сколько |
|---|---|---|
| `cards/` | новые карточки из `cards/index.json`, у которых нет своей плитки | 11 |
| `parts/` | вторые и следующие части карточек из `tree/curriculum.json` | 65 |

У каждой иконки два файла с одинаковым рисунком:
- `<id>.xml` — векторный ресурс Android. Его можно положить в `res/drawable` как есть.
- `<id>.svg` — тот же рисунок для загрузки по сети.

Соответствие «карточка или часть → файл» лежит в `index.json`. Ключ — route карточки (`cards_colours`) или ID части (`b2_wish_past`). Посмотреть все иконки разом можно в `preview.png`.

## Что нужно в приложении, чтобы иконки появились

Сейчас приложение эти файлы не читает:

- **Плитка карточки.** У карточки из папки на плитке «Теории» стоит иконка самой папки, это `theoryTiles()` в `InfoCardsScreen.kt`. Чтобы показывалась своя иконка, плитке нужно брать иконку из `icons/index.json`, если она там есть.
- **Часть.** Части на плитках не показываются вообще. Иконку части можно показывать на экране курса, рядом с названием части.

Сделать это можно двумя способами:

1. **Положить `.xml` в `res/drawable`.** Плюс: показ как у старых иконок, через `painterResource`. Минус: новые иконки будут появляться только с новой версией приложения.
2. **Загружать `.svg` по сети.** Подходит Coil, он уже подключён, плюс декодер `io.coil-kt:coil-svg` той же версии. Новые иконки тогда появляются без обновления приложения, как и карточки.

## Как добавить или поправить иконку

Рисунки описаны в `designs_cards.py` и `designs_parts.py`, общие функции — в `neon.py`: шрифт из одной линии, рамки, круги, стрелки. Собрать файлы заново:

```
python3 icons/build.py
```
